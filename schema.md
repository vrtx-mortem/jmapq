# Produced JSON schema

This document describes the JSON payload generated by `jmapq.py` and written to `map.json`.

## Top-level shape

```json
{
  "units": [Unit],
  "errors": [Error]
}
```

- `units`: parsed Java compilation units.
- `errors`: per-file failures collected during parsing.

## Type model (compact)

```ts
type JSONScalar = string | number | boolean | null;
type JSONValue = JSONScalar | JSONValue[] | { [key: string]: JSONValue };

type Payload = {
  units: Unit[];
  errors: ErrorItem[];
};

type ErrorItem = {
  path: string;
  error: string;
  error_type: string;
};

type Unit = {
  path: string;
  package: string | null;
  imports: string[];
  classes: ClassInfo[];
};

type ClassInfo = {
  name: string;
  qualified_name: string;
  modifiers: ModifierInfo[];
  annotations: AnnotationInfo[];
  methods: MethodInfo[];
  span: SourceSpan | null;
};

type MethodInfo = {
  name: string;
  return_type: TypeRef | null;
  parameters: ParameterInfo[];
  throws: string[];
  modifiers: ModifierInfo[];
  annotations: AnnotationInfo[];
  span: SourceSpan | null;
};

type ParameterInfo = {
  name: string;
  type: TypeRef | null;
  modifiers: ModifierInfo[];
  annotations: AnnotationInfo[];
  span: SourceSpan | null;
};

type TypeRef = {
  name: string;
  type_args: TypeRef[];
  annotations: AnnotationInfo[];
};

type AnnotationInfo = {
  name: string;
  elements: JSONValue;
  span: SourceSpan | null;
};

type ModifierInfo = {
  name: string;
};

type SourceSpan = {
  lineno: number | null;
  end_lineno: number | null;
  col_offset: number | null;
  end_col_offset: number | null;
};
```

## Annotation `elements` normalization

`elements` is always JSON-safe and may be:

- `null`
- primitive (`string`, `number`, `boolean`)
- list / object
- nested annotation object
- normalized operator/member object
- unknown node object

Unknown nodes are preserved, not dropped:

```json
{
  "_kind": "UnknownNode",
  "node_type": "SomeAstType",
  "repr": "<jast._jast.SomeAstType object at 0x...>",
  "span": {
    "lineno": 10,
    "end_lineno": 10,
    "col_offset": 4,
    "end_col_offset": 20
  }
}
```

## Minimal example

```json
{
  "units": [
    {
      "path": "tests/fixtures/foo.java",
      "package": "com.foo.atlassian.jira.common.rest",
      "imports": ["jakarta.ws.rs.GET"],
      "classes": [
        {
          "name": "DashboardItemResource",
          "qualified_name": "com.foo.atlassian.jira.common.rest.DashboardItemResource",
          "modifiers": [{ "name": "Public" }],
          "annotations": [{ "name": "Path", "elements": ["dashboard/..."], "span": null }],
          "methods": [],
          "span": { "lineno": 22, "end_lineno": 36, "col_offset": 0, "end_col_offset": 0 }
        }
      ]
    }
  ],
  "errors": []
}
```
